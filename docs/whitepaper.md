# Quantsiv Whitepaper

## Abstract
Quantsiv detects quantum-vulnerable cryptography in code and TLS.

## Problem
Quantum computers will break RSA/ECDSA.

## Solution
Scans via GitHub App, uses cbomkit-lib and sslyze, provides dashboard and compliance report.
