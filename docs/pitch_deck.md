# Quantsiv Pitch Deck

## Problem
- Quantum computers will break RSA, ECDSA, DH, and similar cryptography.
- Regulatory mandates (EO-14412, NIST PQC standards) require inventory and migration.
- Adversaries are harvesting encrypted data now for later decryption.

## Solution
- Detect quantum-vulnerable cryptography in source code and TLS via GitHub App and Action.
- Analyze using cbomkit-lib, sslyze, cyclonedx-python-lib.
- Provide findings dashboard, risk score, plain-English explanations, and one-click compliance PDF.
- Optional: automated PR remediation, PQC library recommendations, API access.

## Business Model
- Free: 1 repo, 1 seat.
- Developer: $99/mo, unlimited repos, 3 seats, API access, compliance PDF, CI/CD Action.
- Team: $299/mo, unlimited repos, 15 seats, all Developer features plus advanced analytics.
- Enterprise: Custom pricing, unlimited repos, custom seats, managed PQC service, SLA, dedicated support.
